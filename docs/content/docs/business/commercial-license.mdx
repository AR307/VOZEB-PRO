# 商业授权

VOZEB PRO 社区版采用 AGPL-3.0。遵守 AGPL-3.0 并履行对应源代码公开义务时，可以免费使用和商用；不希望公开受协议约束的代码，或需要向第三方交付二次开发系统时，可以购买商业授权。

| 授权类型 | 价格 | 适用场景 |
| --- | ---: | --- |
| 闭源自营授权 | 人民币 2,999 元/年 | 一个授权主体运营一个网站、SaaS、应用或企业内部产品，不向第三方交付整套系统 |
| 无限 OEM 授权 | 人民币 6,999 元/年 | 一个交付主体二次开发后向最终客户销售、部署或交付，授权期内不限最终客户数量 |

## 如何选择

- 只运营自己的产品，或者只在自己的企业内部使用：选择闭源自营授权。
- 要给甲方私有化部署、销售二开系统或以自己的品牌承接交付：选择无限 OEM 授权。
- 愿意继续遵守 AGPL-3.0 并公开对应源代码：不需要购买商业授权。

无限 OEM 的“不限客户数量”不包含转授权、发展下级代理、直接售卖原始源码或允许最终客户继续对外转售。部署、定制开发、技术支持、模型 API 和服务器等费用也不包含在授权价格内。

完整的允许事项、限制、授权期限、第三方组件边界和申请流程，以 GitHub 仓库中的[《VOZEB PRO 商业授权说明》](https://github.com/csyqlz/VOZEB-PRO/blob/main/COMMERCIAL_LICENSE.md)为准。公开说明不会自动授予商业权利，实际授权以付款后签发的授权书或双方合同为准。
