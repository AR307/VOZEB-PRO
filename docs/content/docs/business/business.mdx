# 商务合作

如果你希望围绕 VOZEB PRO 做商业合作、私有化部署、二次开发或模型渠道接入，可以直接通过邮箱联系项目维护者。

## 商业授权

- 闭源自营授权：人民币 2,999 元/年，用于自己闭源运营网站、SaaS、应用或企业内部系统。
- 无限 OEM 授权：人民币 6,999 元/年，用于向不限数量的最终客户销售、部署或交付二次开发系统。

价格只包含软件商业使用权，不包含部署、定制开发、技术支持、模型 API 或服务器费用。具体允许事项和限制见[商业授权](/docs/business/commercial-license)。

## 适合沟通的方向

- 私有化部署、内网部署和团队版落地。
- 定制画布节点、生成流程、素材管理或后台能力。
- 接入自有 OpenAI 兼容接口、模型渠道或提示词仓库。
- 围绕 AI 图片、视频、文本生成工作流做联合方案。
- 商业授权、技术支持、交付咨询或联合方案评估。

## 建议提供的信息

- 你的业务场景和预期用户规模。
- 需要部署的环境、数据保存方式和安全要求。
- 需要接入的模型、渠道、支付或账号体系。
- 期望的交付范围、时间和预算区间。
